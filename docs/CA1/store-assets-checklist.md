## Screenshot Plan
1. The player running forward with the gameplay UI visible.
2. The player approaching an obstacle on the track.
3. The player jumping over an obstacle.
4. The player approaching a left or right turn.
5. The player running through a different dream environment, if implemented.

The screenshots will show actual gameplay features when they are implemented and will not include misleading promotional content.

## Asset Sources
- **App icon:** Created based on the game's visual theme.
- **Feature graphic:** Created using the game's visual style and gameplay elements.
- **Screenshots:** Captured directly from the game on an Android device.

The final assets are planned for Week 10.
